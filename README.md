# Unsupervised & Reinforcement Learning Practical

This practical covers two AI/ML concepts:

* **Unsupervised Learning:** Customer segmentation using K-Means Clustering.
* **Reinforcement Learning:** Understanding agents, actions, rewards, exploration, and exploitation using a delivery-route example.

## Topics Covered

* K-Means Clustering
* Customer Segmentation
* Cluster Interpretation
* Reinforcement Learning
* Agent, Action & Reward
* Exploration vs Exploitation

## Tools Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

The practical demonstrates how machine learning can be applied to business problems such as customer segmentation and delivery-route optimization.
